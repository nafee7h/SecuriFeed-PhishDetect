# SecuriFeed — PhishDetect

A modern cybersecurity-inspired phishing URL detection dashboard built using HTML, CSS, and JavaScript.

---

# Overview

SecuriFeed — PhishDetect is a frontend cybersecurity project designed to detect suspicious and phishing URLs using rule-based threat analysis techniques.

The system analyzes URLs and generates:
- Risk scores
- Threat classifications
- Security recommendations
- Live monitoring activity
- Cybersecurity news feeds

The project is designed as a portfolio-grade internship project with a futuristic dashboard UI and interactive threat visualization.

---

# Features

## Phishing URL Detection
Detects suspicious URLs using:
- HTTP vs HTTPS checks
- IP-based URL detection
- Suspicious keywords
- Typo-squatting indicators
- Excessive subdomains
- Long suspicious URLs
- Hyphen abuse
- Suspicious TLDs

---

## Dynamic Risk Scoring

Generates:
- Risk score (0–100)
- Threat level
- Threat descriptions
- Recommendations

Threat levels:
- SAFE
- MEDIUM RISK
- HIGH RISK
- DANGEROUS
